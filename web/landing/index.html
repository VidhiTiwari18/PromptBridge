How it works

Three steps, no copy-paste.

The extension reads the page you're already looking at. Nothing to configure, nothing to install beyond the browser tool.

↓
01
Capture
Click the extension on any open Claude or ChatGPT conversation. It reads the messages already on your screen.
✦
02
Summarize
Gemini condenses the thread into a dense, structured context package — goal, key facts, current state.
→
03
Transfer
Open the other platform and drop the summary in. The new conversation starts already caught up.
Under the hood

Built like a real product, not a demo.

Account-based, not just local storage
JWT authentication and a Postgres database mean your captured conversations persist across sessions and devices.
Reads the live page, not an API export
A Manifest V3 content script scrapes the conversation directly from the DOM — no manual export step.
Structured summaries, not a paragraph dump
Every summary follows the same shape: goal, key facts, current state, next step — built for a model to pick up quickly.
Works with the tools you already have open
No new app to switch to. It lives in your toolbar and acts on whatever tab is active.

Stop re-explaining your context.

Free, open-source, and takes about a minute to load into Chrome.
